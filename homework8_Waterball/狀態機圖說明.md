# 狀態機圖說明

本文件對應 [狀態機圖.puml](狀態機圖.puml)。圖描述 Waterball 社群機器人的執行狀態、事件、守衛條件與轉移動作。

## 圖的閱讀方式

```text
來源狀態 --> 目標狀態 : 事件 [守衛條件] / 動作
```

- **事件**：觸發狀態轉移的社群事件或指令。
- **守衛條件**：中括號內；條件成立才可轉移。
- **動作**：斜線 `/` 後；轉移發生時執行。
- **entry**：進入狀態時執行的動作。
- 無對應轉移：維持目前狀態；指令不符合權限或額度時為靜默失敗。

## 初始狀態

機器人開始時依線上人數進入 Normal 的一個子狀態：

| 條件 | 初始狀態 |
| --- | --- |
| `onlineCount < 10` | Default Conversation |
| `onlineCount >= 10` | Interacting |

## Normal 的子狀態

### Default Conversation

| 類型 | 行為 |
| --- | --- |
| 進入 | 從 `good to hear` 重設輪播回覆。 |
| 聊天訊息 | 輪播：`good to hear`、`thank you`、`How are you`。 |
| 新貼文 | 留言 `Nice post`，標記發文者。 |
| 登入且 `onlineCount >= 10` | 轉移至 Interacting。 |

### Interacting

| 類型 | 行為 |
| --- | --- |
| 進入 | 從 `Hi hi😁` 重設輪播回覆。 |
| 聊天訊息 | 輪播：`Hi hi😁`、`I like your idea!`。 |
| 新貼文 | 留言並標記 `@bot` 與所有線上成員；成員依登入順序排列。 |
| 登出且 `onlineCount < 10` | 轉移至 Default Conversation。 |

## Record 的子狀態

| 狀態 | 行為與轉移 |
| --- | --- |
| Waiting | 無講者時進入；收到 `go broadcasting` 後轉移至 Recording。 |
| Recording | 每個 `speak` 事件都記錄語音文字；收到 `stop broadcasting` 後輸出 Record Replay、標記錄音者，轉回 Waiting。 |

## KnowledgeKing 的子狀態

| 狀態 | 行為與轉移 |
| --- | --- |
| Questioning | 出題；第一位標記 `@bot` 且答對的人得 1 分。尚有題目時出下一題；全部答完或 1 小時後轉移至 Thanks For Joining。 |
| Thanks For Joining | 公布勝者或平手。無講者時以廣播語音公布；有講者時以聊天室訊息公布。 |

## 跨主要狀態的指令

| 來源 | 指令與條件 | 目標 | 動作 |
| --- | --- | --- | --- |
| Default Conversation／Interacting | `record @bot`，`quota >= 3` | Waiting／Recording | 先依原 Normal 子狀態回覆；扣 3 額度；設定錄音者；依是否已有講者決定子狀態。 |
| Default Conversation／Interacting | `king @bot`，管理員，`quota >= 5` | Questioning | 先依原 Normal 子狀態回覆；扣 5 額度；開始知識王並出第 0 題。 |
| Waiting／Recording | `stop-recording @bot`，發送者為錄音者 | Default Conversation／Interacting | 有錄音內容時輸出 Record Replay；依線上人數回到對應 Normal 子狀態。 |
| Questioning／Thanks For Joining | `king-stop @bot`，管理員 | Default Conversation／Interacting | 依線上人數回到對應 Normal 子狀態。 |
| Thanks For Joining | `20 seconds elapsed` | Default Conversation／Interacting | 依線上人數回到對應 Normal 子狀態。 |

## KnowledgeKing 內部指令與轉移

| 指令／事件 | 條件 | 結果 |
| --- | --- | --- |
| 正確回答 | 第一位答對者、仍有題目 | 得 1 分，出下一題。 |
| 正確回答 | 第一位答對者、最後一題 | 得 1 分，轉移至 Thanks For Joining。 |
| `1 hour elapsed` | — | 轉移至 Thanks For Joining。 |
| `play again @bot` | `quota >= 5` | 扣 5 額度；重新開始 Questioning，從第 0 題開始。 |

## PlantUML 排版設定

圖採平面六狀態布局：Default Conversation、Interacting、Waiting、Recording、Questioning、Thanks For Joining。

| 設定 | 用途 |
| --- | --- |
| `left to right direction` | 由左至右排列狀態。 |
| `skinparam linetype ortho` | 使用直角轉移線。 |
| `skinparam nodesep 120` | 增加狀態框的水平距離。 |
| `skinparam ranksep 180` | 增加狀態框的垂直距離。 |
| `skinparam padding 25` | 增加圖形整體留白。 |
| `\\n` | 將長轉移標籤分行，避免文字重疊。 |
