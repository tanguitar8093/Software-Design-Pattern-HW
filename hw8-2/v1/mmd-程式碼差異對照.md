# v1 程式碼與 OOA-Clean.mmd 差異對照表

本文件逐一比對 [OOA-Clean.mmd](./OOA-Clean.mmd) 上畫出的屬性/方法，與 `models/` 底下實際程式碼的落差，並說明每一項差異背後的原因。分類方式：

- 🆕 **圖上沒有，程式碼新增**
- 🚫 **圖上有，程式碼未以相同形式實作**
- 🔁 **圖上有，但實作方式略有出入（非新增/非缺少，僅形式不同）**

---

## 總覽（最關鍵的一項）

| 項目                        | 說明                                                                                                                                                                                                                                                                                                                                                                                                                    |
| :-------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🆕 `BotState`（`enums.py`） | mmd 完全沒有畫出任何「狀態」類別或欄位，`Bot` 在圖上只有 `quota`、`replyCycleIndex` 兩個資料欄位，沒有任何欄位記錄「目前是正常/錄音/知識王的哪個子狀態」。但 README 的核心需求就是「機器人依狀態決定行為」，若不新增一個狀態欄位，程式邏輯完全無法運作。這是刻意為之：v1 對應的正是「狀態邏輯尚未被抽出」的最原始版本，所以我用一個列舉 `BotState` 把狀態塞進 `Bot` 內部，之後 v2 才會用 State Pattern 把它獨立成類別。 |
