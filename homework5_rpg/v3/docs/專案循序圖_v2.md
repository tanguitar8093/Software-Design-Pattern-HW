# 專案循序圖 v2

這份是精簡版，只保留整個 RPG 專案最重要的互動節點，參考 `v1/sequence_diagram.md` 的呈現方式。

如果你想看比較完整的版本，請搭配 [專案循序圖.md](/home/allentan/workspaces/Software-Design-Pattern-HW/homework5_rpg/v3/docs/專案循序圖.md) 一起看。

## 1. 主流程精簡版

```mermaid
sequenceDiagram
    actor User as 使用者
    participant Main as main.py
    participant U as Unit
    participant E as BattleEngine
    participant S as State
    participant P as Strategy
    participant A as Action
    participant T as Target Unit
    participant O as DeathObserver

    User->>Main: 啟動程式並輸入軍隊資料
    Main->>U: 建立英雄 / 隊友 / 怪物
    Main->>P: 指派 HumanStrategy / AIStrategy
    Main->>A: 建立技能物件並放入 skills
    Main->>E: 建立 BattleEngine 並開始戰鬥

    loop 直到遊戲結束
        E->>U: 取出目前行動單位
        E->>S: on_round_begin(unit)

        alt 狀態阻止行動
            E->>S: countdown(unit)
        else 可以行動
            E->>P: select_action(unit)
            P-->>E: action
            E->>P: select_targets(unit, action, board)
            P-->>E: targets
            E->>A: execute(unit, targets)

            alt 技能造成傷害或狀態效果
                A->>T: take_damage / change_state / heal / attach
            end

            opt 目標死亡
                T->>O: notify()
                O-->>T: on_unit_death(dead_unit)
            end

            E->>S: countdown(unit)
        end
    end

    E-->>User: 輸出勝負結果
```

## 2. 單一回合重點版

這張圖只聚焦一個角色輪到自己時，主流程會經過哪些設計模式。

```mermaid
sequenceDiagram
    participant E as BattleEngine
    participant S as State
    participant P as Strategy
    participant A as Action
    participant T as Target
    participant O as Observer

    E->>S: on_round_begin(unit)

    alt 不能行動
        E->>S: countdown(unit)
    else 可以行動
        E->>P: select_action(unit)
        P-->>E: action
        E->>P: select_targets(unit, action, current_board)
        P-->>E: targets
        E->>A: execute(unit, targets)

        alt 攻擊命中且 target 死亡
            A->>T: take_damage(...)
            T->>O: notify()
        else 其他技能效果
            A->>T: heal / change_state / attach / summon
        end

        E->>S: countdown(unit)
    end
```
