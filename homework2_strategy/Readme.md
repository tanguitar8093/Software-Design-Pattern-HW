1. 過程碰到的困難

- 循序圖沒有影片樣本, 憑感覺畫, 沒有頭緒 based, 各種策略要擺哪裡? 箭頭怎麼畫?
- reverse=true: 花很多時間去想辦法, 如何不用 reverse=true, 得知要用裝飾者模式
- 了解 next 和 UML 雛型:

  - 看完裝飾者模式, 只懂 4~5 成, 主要知道 next 是幹嘛用的, 圖 "大概" 長甚麼樣子
  - 還需要看很多不在道館 2 範圍的影片才能再進一步理解裝飾者模式

- force 不知道怎麼抓
  - 靠助教指導找出沒發現忽略的關聯和 force 畫法
  - 單純模仿, 還不太會抓
  - 感覺實作樣本不夠多, 需要持續累積做中學

2. 心得

- OOD 圖畫出來後, v2 重構 v1 按圖施工的過程相當療育舒服
- 演算法的部分是請 AI 實作, 考慮設計模式才是重點, 局部細節卡住就 call AI help
