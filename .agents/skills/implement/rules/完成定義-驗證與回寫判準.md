# Rule 1 - task 只有在實作與對應驗證都完成後才算完成

- Level: `MUST`
- 單一 task 的完成條件至少包含：所需變更已實作、對應檔案已寫入，且已完成與該 task 直接相關的驗證。
- 驗證方式應依 task 類型收斂，例如 targeted tests、lint、型別檢查、手動流程驗證、契約對照或啟動檢查。
- 不得把「程式已寫完但還沒驗證」視為已完成。
- `[TDD-RED]` 已綠且 mapping 對時，「所需變更」就是那張新測，不是必須先有產品 diff。

## Good Example

- 這個例子是好的，因為它把實作與驗證都跑完後才認定 task 完成。

```md
agent 完成 `roomStore.js` 的修改後，接著跑對應測試與啟動檢查。
確認驗證通過後，才把該 task 視為完成。
```

## Bad Example

- 這個例子是壞的，因為它只完成了程式修改，卻沒有任何完成證據。

```md
agent 寫完 `gameHandler.js` 後就直接說「這個 task 已完成」，但沒有跑任何測試、lint 或契約對照。
```

# Rule 2 - task 完成後必須立即回寫 `[X]`，且不得提前打勾

- Level: `MUST`
- 當且僅當 task 的實作與驗證都完成時，才可將對應 task 從 `- [ ]` 改寫為 `- [X]`。
- 不得先為了追蹤方便而預先打勾。
- 同一 `[SLICE <CASE_ID>]` 的剩餘 TDD 鏈，在各則都有對應證據段後，可一次回寫該鏈已完成的各則；不得把其他 `CASE_ID` 或尚未有證據的 task 一起改成完成。
- 回寫時只修改實際完成的 task，保留其他未完成 task 狀態不變。

## Good Example

- 這個例子是好的，因為同切片三段證據齊了才勾三則，其他切片不動。

```md
FE-E2E-001C 子代理交回 RED／GREEN／REFACTOR 三段證據。
agent 把 T026–T028 改成 `[X]`，T029 另一切片仍 `[ ]`。
```

## Bad Example

- 這個例子是壞的，因為提早打勾，或把別的切片一起勾掉。

```md
agent 剛開始改 T026 就先把 T026–T028 打勾。
或一次把 T036–T047 改成 `[X]`。
```

# Rule 3 - 完成回報應留下可追蹤的驗證證據與下一步狀態

- Level: `SHOULD`
- 每輪完成回報應說明：完成了哪些 task、做了哪些驗證、是否補強 repo hygiene、下一個已解鎖 task 是什麼或為何暫停。
- 回報應聚焦執行狀態與關鍵決策，不需要把所有細節寫成冗長 changelog。

## Good Example

- 這個例子是好的，因為它讓使用者能快速知道完成面、證據與續跑位置。

```md
已完成 `T001`、`T002`。
驗證：前後端 workspace 安裝與啟動檢查通過。
已補強 `.gitignore`。
下一個已解鎖 task：`T003`。

下一步：繼續實作 /implement（T003）
```

## Bad Example

- 這個例子是壞的，因為它只說做完了，卻沒有留下驗證或續跑狀態。

```md
今天完成很多東西，應該差不多可以用了。
```

# Rule 4 - Add 的 RED 已綠且 mapping 對時，仍應在同一子代理內走完並回寫

- Level: `MUST`
- 若切片子代理回報 RED／ALIGN 測已映射本則 testplan、執行為綠、且未改產品碼，應視為該 RED／ALIGN 已完成；同一子代理必須繼續 GREEN（可無實作）與 REFACTOR（可無重構），不得停下來等人或再開一次子代理。
- 父代理在三段（或剩餘各段）證據齊全後回寫對應 `[X]`。
- 不得因為「沒有先紅」而拒絕回寫或改成等待使用者。
- 不得把本則改成 Keep、回頭改 `tasks.md` 分類、或刪掉這張新測。產品是否已符合不決定工單該不該存在。

## Good Example

- 這個例子是好的，因為覆蓋率 Add 在同一子代理走完三格工單。

```md
同一 Task：T013 RED 已綠／mapping 對；T014 GREEN 本則無實作；T015 REFACTOR 本則無重構
父代理一次回寫 T013–T015
下一個已解鎖：T016 BE-API-001D
```

## Bad Example

- 這個例子是壞的，因為把合法已綠當成未完成，或回頭改成 Keep。

```md
T013 測已寫且綠，但不打勾，下一步等待正確紅燈。
或把 T013 從 [TDD-RED] 改成 Keep，刪新測，直接跳 001D。
```
