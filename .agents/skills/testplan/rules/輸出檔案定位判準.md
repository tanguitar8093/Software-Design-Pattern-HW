# Rule 1 - 最終 testplan 必須寫到固定路徑

- Level: `MUST`
- `/testplan` 的最終產物路徑固定為 `specs/<NNN-plan-package>/testplan.md`。
- 不可寫入 `system-analyze/` 子目錄，也不可把完成稿只留在聊天訊息、舊檔名 `e2e-test-plan.md` 或任意檔名中。

## Good Example

- 這個例子是好的，因為輸出與同 package 的 `spec.md` 並列。

```text
specs/001-overtime-correction/testplan.md
```

## Bad Example

- 這個例子是壞的，因為把測試計畫塞進 system-analyze，或沿用已淘汰檔名。

```text
specs/001-overtime-correction/system-analyze/testplan.md
specs/001-overtime-correction/e2e-test-plan.md
```

# Rule 2 - `plan-package` 必須與上游 spec 目錄對齊

- Level: `MUST`
- `plan-package` 必須沿用同功能的 `specs/<NNN-plan-package>/` 目錄名，採 `NNN-` 三位數前綴加英文小寫 kebab-case slug。
- 若使用者已指定既有 package，應寫入該 package，不可另開平行目錄。

## Good Example

- 這個例子是好的，因為 testplan 與 spec 落在同一 package。

```text
specs/001-overtime-correction/spec.md
specs/001-overtime-correction/testplan.md
```

## Bad Example

- 這個例子是壞的，因為測試計畫與規格分散在不同 package。

```text
specs/001-overtime-correction/spec.md
specs/002-testplan-only/testplan.md
```

# Rule 3 - 標題與小標必須對齊固定契約

- Level: `MUST`
- H1 固定為 `# 測試計劃：{{FEATURE_TITLE}}`，功能中文名與同 package 的 `spec.md` 對齊。
- 小標固定三行、分行書寫：`**功能分支**:`、`**建立日期**:`、`**狀態**:`；其中功能分支值必須以 inline code 包住，且與所在 `plan-package` 相同。
- `**建立日期**:` 使用本次產出日期（`YYYY-MM-DD`）；`**狀態**:` 第一版預設 `草稿`。

## Good Example

- 這個例子是好的，因為標題與小標可對回目錄。

```md
# 測試計劃：加班資料與計薪方式更正功能

**功能分支**: `001-overtime-correction`
**建立日期**: 2026-08-25
**狀態**: 草稿
```

## Bad Example

- 這個例子是壞的，因為 metadata 格式不固定、或沿用舊 e2e 標題。

```md
# 端對端測試計畫：加班更正

**功能**: overtime ｜ **日期**: 2026-08-25
```

# Rule 4 - 上游介面檔按需引用，不硬停

- Level: `MUST`
- 撰寫本計畫前必須已有同 package 的 `spec.md`。`plan.md`、`system-analyze/api-plan.md`、`system-analyze/ui-plan.md` 若存在則引用，不存在則不要發明端點或畫面。
- 不可因為缺少 `api-plan.md` 或 `ui-plan.md` 就停止；也不可在缺檔時腦補 API 路徑或 UI 頁面。
- 沒有的 public seam 不要編造 `BE-API-*` 或 `FE-E2E-*`。

## Good Example

- 這個例子是好的，因為有 API 契約就引用，沒有前端計畫就不造前端切片。

```text
已存在 spec.md 與 api-plan.md
無 ui-plan.md、本輪只有 API
→ 只寫 BE-API 切片與 BE-JOURNEY，不發明 FE-E2E
```

## Bad Example

- 這個例子是壞的，因為缺 ui-plan 仍硬停，或沒有畫面卻編造前端切片。

```text
缺 system-analyze/ui-plan.md
仍停止並要求先跑 /ui-plan
或：沒有畫面仍寫 FE-E2E-001A
```
