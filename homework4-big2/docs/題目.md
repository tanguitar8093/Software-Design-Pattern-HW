**難度：** ★★☆☆☆

## 📜 需求大綱

你要開發一款「大老二」撲克牌遊戲。你必須仔細實現每一個遊戲規則，並確保模組具備良好的**擴充性**，以支援未來可能新增的牌型或規則變動。

## 🕹️ 遊戲流程 (Game Flow)

1.  **遊戲初始化：**
    - 共有四位玩家（索引 $0, 1, 2, 3$）。
    - 若目前為玩家 $i$，則下一位為 $(i+1) \pmod 4$。
2.  **發牌：** 52 張牌輪流發給四位玩家，直到發完為止。
3.  **第一回合：**
    - 由擁有 **梅花 3 (C[3])** 的玩家先出牌，且該牌型**必須包含梅花 3**。
    - 後續玩家可選擇：
      - **PASS**：放棄出牌。
      - **打牌**：打出比目前頂牌更強的「相同種類」牌型。
    - 直到連續三位玩家 PASS，該回合結束。
4.  **後續回合：**
    - 清空檯面與頂牌。
    - **上一回合的頂牌玩家**為新回合的出牌者，且新回合的第一輪**不能喊 PASS**。
5.  **結束條件：** 任一玩家手牌歸零，遊戲立刻結束並宣告該玩家為 **贏家 (Winner)**。

## 🎴 牌型與比較規則

僅有**相同種類**的牌型可以互相比較。

- **單張 (Single)：** 1 張牌。先比數字，數字同則比花色。
  - 數字：$3 < 4 < \dots < A < 2$
  - 花色：$C < D < H < S$
- **對子 (Pair)：** 2 張數字相同的牌。以兩張中「較大的牌」作為比較基準。
- **順子 (Straight)：** 5 張數字連續的牌。以其中「最大的牌」作為比較基準。
  - 注意：包含 $2-3-4-5-6$ 或 $10-J-Q-K-A$ 等組合。
- **葫蘆 (Full house)：** 3 張數字相同 + 2 張數字相同。以「三張相同數字」的部分作為比較基準。

## ⌨️ 輸入與輸出格式

### 輸入 (Input)

1.  第一行：52 張牌（由底至頂，發牌從最右邊開始取）。範例：`C[3] D[3] ... S[2]`
2.  第二至五行：四位玩家的名字。
3.  後續每行：玩家動作。
    - `-1` 代表 PASS。
    - `0 2` 代表打出索引為 0 與 2 的手牌。

### 輸出 (Output)

1.  新回合開始：`新的回合開始了。`
2.  玩家輪次：`輪到 <玩家名字> 了`。
3.  手牌顯示：需包含索引列與牌面，且**需由小到大排序**並對齊。
4.  打牌結果：
    - 成功：`玩家 <名字> 打出了 <牌型名稱> <牌面...>`
    - 失敗：`此牌型不合法，請再嘗試一次。`
    - PASS：`玩家 <名字> PASS.`
    - 非法 PASS：`你不能在新的回合中喊 PASS`
5.  結束：`遊戲結束，遊戲的勝利者為 <名字>`
